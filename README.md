# Atividade - Colaboradores

Este repositório simula o trabalho de dois colaboradores em branches separadas.

## Colaboradores
- Ana Costa
- Bruno Lima

## Regras aplicadas
- Cada funcionalidade desenvolvida em branch separada (`feature/`)
- No meio de cada funcionalidade (após 1 commit), um bug urgente foi corrigido em branch `bugfix/`
- Após o bugfix, o desenvolvimento da funcionalidade foi retomado e concluído
- Cada funcionalidade deve ser submetida via Pull Request no `master`
